# Training, Onboarding & Tabletop Library

## Structure

- [`onboarding/`](./onboarding/) — analyst ramp-up docs, mapped to the `domains/` structure so a new hire's reading list is just "read the README in each domain you'll cover."
- [`tabletop-library/`](./tabletop-library/) — scenario library plus after-action reports. Each tabletop scenario should cite the playbook(s) it's testing, and each after-action report should link back to any playbook/runbook it resulted in updating — this is the feedback loop that keeps the playbook library honest.
