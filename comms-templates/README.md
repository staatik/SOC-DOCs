# Communications Templates

Pre-drafted templates so incident-time comms aren't written from scratch under pressure.

## Contents

- **Breach notification templates** — regulatory and customer-facing, pre-reviewed by legal/compliance so they're ready to fill in, not draft, during an actual incident.
- **Executive status update templates** — for use mid-incident, distinct from the routine reporting cadence in `metrics/`.
- **Internal stakeholder templates** — engineering/IT handoff notices, all-hands comms for major incidents.

Each template should note who has pre-approved its use (legal, comms, leadership) so there's no ambiguity about whether it can be sent without additional sign-off.
