# GRC / Compliance Crosswalk

Maps SOC controls and documentation to external frameworks, so a single control update propagates to every framework it satisfies instead of being re-derived per audit.

## Contents

- **Framework crosswalk** — a table mapping SOC-CMM domains / internal controls to NIST CSF, ISO 27001, CMMC, and any customer-driven requirements (SOC 2, etc.), each row linking back to the governing policy or process doc that satisfies it.
- **Audit evidence index** — pointers to where evidence for a given control lives (which runbook execution logs, which review records) rather than duplicating the evidence itself.
- **Regulatory obligations** — breach notification timelines and other statutory requirements that constrain the playbooks in `domains/incident-response/`.
